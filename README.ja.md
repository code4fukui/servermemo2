# servermemo2

[servermemo](https://github.com/code4fukui/servermemo) の代替バージョンです。このプロジェクトは、サーバーにメモを保存するためのエンドツーエンド暗号化を備えた、シンプルなWebベースのメモアプリケーションを提供します。

## 仕組み

セキュリティを確保するため、公開鍵暗号方式を用いたクライアント・サーバーモデルを採用しています。

- **鍵の生成**: サーバーとクライアント（ブラウザ）は、それぞれ独自の公開鍵・秘密鍵のペアを持ちます。
  - サーバーの鍵は一度だけ生成され、`.env` ファイルに保存されます。
  - クライアントの鍵は初回アクセス時に生成され、ブラウザの `localStorage` に保存されます。
- **暗号化**: メモを保存する際、クライアントは自身の秘密鍵とサーバーの公開鍵を使用して（ECDHにより）共有シークレットを生成します。その後、送信前にこのシークレットを用いて（AESにより）メモを暗号化します。
- **復号と保存**: サーバーは暗号化されたデータを受信します。サーバー自身の秘密鍵とクライアントの公開鍵を使用して同じ共有シークレットを計算し、メモを復号して、その**平文**コンテンツをディスク上のファイルに保存します。
- **取得**: メモは公開ディレクトリに保存され、クライアントの公開鍵ごとに整理されます。「load」ボタンを押すと、この場所から平文のメモを直接取得します。

## 要件

- [Deno](https://deno.land/)

## セットアップと使い方

### 1. サーバーの鍵の生成

まず、サーバーの公開鍵と秘密鍵を生成します。以下のコマンドを実行すると、プロジェクトのルートディレクトリに `.env` ファイルが作成されます。

```sh
deno run -A makekeys.js
```

### 2. クライアントの設定

Webクライアントにサーバーの公開鍵を設定する必要があります。

1. 新しく作成された `.env` ファイルから `PUBKEY` の値をコピーします。
2. テキストエディタで `static/index.html` を開きます。
3. 以下の行を探します:
    ```javascript
    const remotepubkey = Base64URL.decode("xsPBu65X8dscFjUIqECDjT1VcNHwa3GNx2PGkd6d-JA");
    ```
4. ハードコードされている鍵の文字列を、`.env` からコピーした `PUBKEY` に置き換えます。

### 3. サーバーの起動

ポート8888（または任意のポート）でサーバーを起動します。

```sh
deno run --allow-net --allow-read --allow-write --allow-env servermemo2.js 8888
```

### 4. Webアプリの利用

ブラウザで [http://localhost:8888/](http://localhost:8888/) を開きます。

- **保存 / 読み込み**: 「save on server」および「load from server」ボタンを使用してメモを管理します。
- **鍵の管理**: 水平線の下にあるボタンを使用して、クライアント側（ブラウザ）の秘密鍵をエクスポート、インポート、または再生成できます。これは、異なるブラウザ間で同じメモを利用する場合に便利です。

## ファイル構成とAPI

- **APIエンドポイント**: `POST /api/{server_public_key_base64url}/{filename}`
  - クライアントは、自身の公開鍵と暗号化されたメモデータを含むCBORエンコードされたペイロードを送信します。
- **データの保存**: サーバーは復号された平文のメモを `static/data/{client_public_key_base64url}/{filename}` に保存します。
  - この `static/data` ディレクトリは公開ディレクトリとして配信されるため、クライアントはメモを直接取得できます。
